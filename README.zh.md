# Synnia

> **化混乱为规范。尽在本地。**

[English Description](./README.md)

你好！👋 我正在开发 Synnia，这是一个开源工具，旨在帮助你在 AI 时代管理创意资产的混乱局面。



## 什么是 Synnia？

Synnia 是一个**数字资产一致性引擎**。

在大多数基于节点的工具（如 ComfyUI）中，节点是*功能*（执行此操作 -> 执行彼操作）。
而在 Synnia 中，节点是**资产**（你的图片、文本、角色）。

你可以在无限画布上放置你的资产，组织它们，并使用"配方"（Recipe）来扩展你的项目，同时保持所有内容的一致性。

我不是一个全职的专业开发者，而且我经常发现现有的节点工具让人望而生畏。我开始构建 Synnia，是因为我想要一个直观易用的工作空间——一个学习曲线平缓、邀请你来"玩耍"而不是强制你"学习"的工具。它专为独立开发者、作家和世界构建者设计，帮助他们保持创意宇宙的连贯性。

## 当前状态（2026年1月）

自初始版本发布以来，项目有了很大进展！以下是目前已实现的功能：

### 核心架构
-   **以资产为中心的架构**：将"数据"（资产）与"视图"（节点）分离。你的数据独立于画布存在。
-   **图引擎 V4**：重写的核心引擎，能够流畅地处理复杂的交互、拖拽和连接。
-   **SQLite 后端**：稳健的本地数据库存储，配合内容寻址存储（CAS）管理资产。
-   **模块化后端**：清晰的 Rust 架构，领域分离（资产、模型、配方）。

### 配方系统 V2
-   **基于 YAML 的配方**：以声明式 YAML 包定义工作流，包含 schema、提示词和执行器。
-   **配方包架构**：自包含的配方包，含 manifest、schema 和提示词模板。
-   **内置配方库**：开箱即用的创作配方：
    - 🎭 **首席叙事官** - 生成完整的角色灵魂档案
    - 🎨 **艺术总监** - 创建视觉蓝图和资产定义
    - 📦 **产品经理** - 生产清单生成
    - 🎬 **媒体配方** - 图像/视频生成工作流
-   **配方 IDE**：内置 Mini-IDE，用于编辑和管理配方，支持多级分类导航。
-   **连线自动填充**：连接时自动填充关联字段值。

### 多提供商 AI
-   **统一模型系统**：单一接口支持多个 AI 提供商：
    - OpenAI（GPT-4o、DALL-E 3）
    - Anthropic（Claude 3.5 Sonnet）
    - Google AI（Gemini 2.0、Imagen）
    - FAL.ai（Flux、Kling）
    - 智谱 GLM
    - OpenAI 兼容端点
-   **多轮对话**：支持对话式配方执行。
-   **统一执行器**：跨所有提供商的标准化结果处理。

### 开发体验
-   **i18n 支持**：完整的国际化，支持中英文。
-   **深度数据编辑器**：用于复杂嵌套数据结构的富编辑器。
-   **MCP Bridge 集成**：AI 助手可以通过 [mcp-server-tauri](https://github.com/hypothesi/mcp-server-tauri) 截图、检查和调试运行中的应用。
-   **TypeScript 绑定**：通过 ts-rs 从 Rust 自动生成类型。

## 路线图

### 近期目标
-   **更多节点类型**：Markdown 编辑器、JSON 查看器、调试/检查节点。
-   **配方分享**：将配方导出为可分享的包。
-   **性能优化**：优化大型画布和大量资产的场景。

### 未来愿景
-   **元配方**：从其他配方 + 资产组合创建新工作流。
-   **插件系统**：通过社区构建的节点和配方扩展 Synnia。
-   **协作**：团队项目的实时同步（探索 CRDT）。

## 技术栈

- **前端**：React 19 + TypeScript + @xyflow/react + Radix UI + TailwindCSS
- **后端**：Rust + Tauri 2.2 + SQLite + Actix-web
- **状态管理**：Zustand + Zundo（撤销/重做）
- **AI**：Vercel AI SDK + 各提供商 SDK

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/l1veIn/Synnia.git
cd synnia

# 安装依赖
pnpm install

# 开发模式运行
pnpm tauri:dev
```
