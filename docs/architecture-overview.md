## 四大可扩展模块

| 模块 | 扩展单位 | 注册方式 | 联动关系 |
|------|----------|----------|----------|
| **NodeRegistry** | NodeType | `NodeRegistry.register()` | 被 Recipe 动态注册 RecipeNode |
| **RecipeRegistry** | YAML 包 | 文件系统加载 → 动态注册 | 触发 Node 注册 + 声明 Executor/Model 需求 |
| **ExecutorRegistry** | Executor 类 | `ExecutorRegistry.register()` | 被 Recipe 选择，调用 Model |
| **ModelRegistry** | ModelPlugin | `ModelRegistry.register()` | 被 Executor 调用，被 Recipe 能力筛选 |

## 设计原则

1. **可扩展性优先**：四大模块均采用注册模式，支持无限扩展
2. **声明式配方**：YAML manifest 声明需求，运行时动态匹配
3. **能力驱动**：Model 通过 capabilities 声明能力，Recipe 通过需求筛选
4. **数据与视图分离**：Asset 是数据，Node 是视图，GraphEngine 管理映射
